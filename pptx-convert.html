Custom (non-auto) keys are migrated by EN-text within the same table
  • Run this once before exporting text for translation.
  • Text containers get names like tr_7f3a91_body (visible in the Selection Pane).
  • Existing valid translation IDs are preserved; duplicates are repaired.
  • Run again after duplicating slides to normalize copied IDs.
  • Text is extracted by PowerPoint paragraph (a:p), not by visual line wrap.
  • Keys are based on Selection Pane names: shapeName + paragraphIndex.
  • Inline bold/italic inside one paragraph is exported as markdown: **bold**, *italic*, ***both***. Keep the same markers in translation cells.
  • Add translation columns to the XLSX, then use the XLSX → PPTX tab to generate localized presentations.
