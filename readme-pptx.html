Babel Fish — PPTX Converter

Simple idea

This tool helps translate a PowerPoint file without manually copying text back and forth.

  • First, run Prepare PPTX to mark IDs and download both the marked PPTX and the XLSX template.
  • Add translation columns to the XLSX.
  • Load the marked PPTX and XLSX, adjust font sizes if needed, and download translated PPTX files.

1. Prepare PPTX

Do this before translating. The tool adds stable names to text blocks, exports a translation XLSX, and gives you a marked PPTX for later steps.

1 Upload the original PPTX

Open the Prepare PPTX tab, drop the presentation, set the source language code, and click Prepare PPTX.

2 Download marked PPTX and XLSX

You get two files: *_marked.pptx and .xlsx. Use the marked PPTX and the spreadsheet for translation and final generation.

XLSX format

tr_7f3a91_body__p0tr_7f3a91_body1Original textPolish textGerman text
tr_6ae152_table__h1a2b3ctr_6ae152_table5150 km, 3 kg WH......
pricing.product_nametr_6ae152_table5Hornet B2......

You can edit the key column. Auto keys (__p<N> for shapes and __h<hash> for table cells) regenerate on each Prepare PPTX run. Custom names you choose survive across runs if you drop the previous XLSX into the optional zone on the Prepare PPTX tab. Add translation columns next to the source column, for example PL, DE, FR. Do not edit shapeName or slideNumber.

Key editor and bulk operations

After Prepare PPTX extracts text, a key editor appears with all entries grouped by slide and table. You can:

  • Inline-rename any single key.
  • Apply a prefix to every key on a chosen slide (e.g. s5_).
  • Apply a basename to a chosen table; paragraphs become <basename>_1, <basename>_2, ...
  • Reset selected keys back to their auto-generated value.

Adding rows to a PPTX table no longer shifts the keys, because table-cell keys are derived from a content hash of the source text.

Inline formatting (bold / italic)

If one paragraph mixes regular, bold, and italic text in PowerPoint, the export uses a small markdown dialect in the cell:

  • **bold** — bold
  • *italic* — italic
  • ***both*** — bold and italic
  • \* — a literal asterisk

Translators should keep the same markers around the matching words in each language. On XLSX → PPTX, group font sizes/colors from the style table merge with inline markers: table bold/italic is the base; markdown refines each part.

If markers are broken (unclosed **), the tool warns and inserts plain text without inline formatting.

2. Merge XLSX (optional)

When you re-export a deck after edits, open Utilities → Merge XLSX to copy translation columns from an old spreadsheet into a new one where key and source text still match.

3. XLSX → PPTX

Open XLSX → PPTX. Load the marked PPTX and the translated XLSX. The table appears only after both files are loaded.

1 Check font-size groups

The table groups similar text styles. Each row has a number, language size fields, a usage count, and a style label.

2 Preview examples

Hover a style label to see a quick preview. Click the label to add that style card to the panel on the right. Use × on a card to remove it.

3 Adjust sizes if needed

You can edit individual size cells. You can also use the multiplier at the top of each language column to shrink all sizes for that language.

4 Save presets and download PPTX

Save preset downloads a JSON with all size settings. Load preset applies it later. At the bottom of the table, use buttons like ↓ PL to download a PPTX for that language.

Important: If you duplicate slides or heavily edit text blocks in PowerPoint, run Prepare PPTX again before using a new XLSX.

Quick FAQ

Can I translate only one language?

Yes. Add only the column you need, for example PL, then download ↓ PL.

Can I leave some cells empty?

Yes. Empty translation cells are skipped.

What should I never change?

Do not change shapeName or slideNumber. You can edit key, language text, and add new language columns.

Простая идея

Инструмент помогает перевести PowerPoint без ручного копирования текста туда-сюда.

  • Сначала Prepare PPTX: стабильные ID, размеченный PPTX и XLSX одним шагом.
  • В XLSX добавляем колонки с переводами.
  • Загружаем размеченный PPTX и XLSX, при необходимости правим размеры шрифта и скачиваем готовые PPTX по языкам.

1. Prepare PPTX

Этот шаг нужно сделать перед переводом. Инструмент добавляет стабильные имена блокам, выгружает XLSX и отдаёт размеченный PPTX для следующих шагов.

1 Загрузите исходный PPTX

Откройте вкладку Prepare PPTX, загрузите презентацию, укажите код исходного языка и нажмите Prepare PPTX.

2 Скачайте размеченный PPTX и XLSX

Вы получите два файла: *_marked.pptx и .xlsx. Их используйте для перевода и финальной сборки.

Формат XLSX

keyshapeNameslideNumberENPLDE
tr_7f3a91_body__p0tr_7f3a91_body1Original textPolski tekstDeutscher Text
tr_6ae152_table__h1a2b3ctr_6ae152_table5150 km, 3 kg WH......

Колонку key можно редактировать. Авто-ключи (__p<N> для shapes и __h<hash> для ячеек таблиц) перегенерируются на каждом Prepare PPTX. Ваши кастомные имена сохраняются между запусками, если бросить предыдущий XLSX в опциональную зону на вкладке Prepare PPTX. Рядом можно добавлять языковые колонки: PL, DE, FR и так далее. Колонки shapeName и slideNumber менять нельзя.

Редактор ключей и массовые операции

После Prepare PPTX появляется редактор ключей со всеми записями, сгруппированными по слайдам и таблицам. В нём можно:

  • Inline-переименовать любой отдельный ключ.
  • Применить префикс ко всем ключам выбранного слайда (например, s5_).
  • Применить базовое имя к выбранной таблице — абзацы станут <basename>_1, <basename>_2, ...
  • Сбросить выделенные ключи обратно к авто-значению.

Добавление строк в таблицу PPTX больше не сдвигает ключи: для ячеек таблицы они формируются как контентный хэш исходного текста.

Inline-форматирование (жирный / курсив)

Если в одном абзаце в PowerPoint смешаны обычный текст, жирный и курсив, в ячейке используется узкий markdown:

  • **жирный** — bold
  • *курсив* — italic
  • ***оба*** — bold и italic
  • \* — звёздочка как символ

Переводчикам нужно сохранять те же маркеры вокруг соответствующих слов. На вкладке XLSX → PPTX размеры/цвета из таблицы стилей объединяются с markdown: bold/italic группы — база, markdown уточняет фрагменты.

Если маркеры битые (незакрытый **), будет предупреждение и вставка plain text без inline-стилей.

2. Merge XLSX (по желанию)

После правок в деке откройте Utilities → Merge XLSX, чтобы перенести колонки переводов из старой таблицы в новую, где совпадают key и исходный текст.

3. XLSX → PPTX

Откройте XLSX → PPTX. Загрузите размеченный PPTX и XLSX с переводами. Таблица появится только после загрузки обоих файлов.

1 Посмотрите группы размеров

Таблица группирует похожие текстовые стили. У каждой строки есть номер, поля размеров по языкам, количество использований и название стиля.

2 Проверяйте примеры

Наведите курсор на название стиля, чтобы быстро увидеть примеры. Нажмите на название, чтобы добавить карточку этого стиля в правую панель. Кнопка × удаляет карточку из панели.

3 Подправьте размеры, если нужно

Можно менять отдельные ячейки с размером. Можно использовать multiplier сверху языковой колонки, чтобы уменьшить все размеры для выбранного языка сразу.

4 Сохраните пресет и скачайте PPTX

Save preset скачивает JSON со всеми настройками размеров. Load preset загружает его обратно. Внизу таблицы есть кнопки вроде ↓ PL — они скачивают PPTX для конкретного языка.

Важно: если вы дублировали слайды или сильно меняли текстовые блоки в PowerPoint, перед новой таблицей снова запустите Prepare PPTX.

Короткий FAQ

Можно сделать только один язык?

Да. Добавьте только нужную колонку, например PL, и скачайте ↓ PL.

Можно оставлять ячейки перевода пустыми?

Да. Пустые ячейки пропускаются.

Что точно нельзя менять?

Не меняйте shapeName и slideNumber. Колонку key, текст в языковых колонках и новые языковые колонки добавлять/править можно.
