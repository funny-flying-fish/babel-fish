XLSX → TXT

What this tab does

Converts translation XLSX files into tab-separated TXT files for InDesign import and applies typography cleanup during export.

  • Supports one or many XLSX files in the same run.
  • Adds a version date automatically.
  • Can add an encoding suffix to filenames.
  • Shows every formatting change in the conversion log.

Input Format

  • Row 1 contains headers or labels.
  • Column A contains language codes such as en_EN, fr_FR, PL.
  • Other columns contain the text values that will become TXT columns.
Tip: Put a project code in square brackets in the filename, for example Translations [PROJ-001].xlsx. If no code is found, the converter uses not-set and writes a warning to the log.

How to Use

1Upload XLSX files

Drop files into the upload zone or click it to browse. Multiple files are supported.

2Choose encoding

Unicode is selected by default and supports Polish and other non-Western characters. Use Mac Roman only for legacy workflows that do not need Central European characters. Windows-1252 is available for older Western European workflows.

3Choose rules

Leave the default rules on for normal production. Disable a rule only when you intentionally need raw text.

4Convert and download

Click Convert. Each source file gets its own download link. Downloads are triggered in a Safari-friendly way.

Formatting Rules

OptionEffect
Numeric formattingNormalizes number grouping and decimal separators by language.
Unit spacingAdds non-breaking spaces between numbers and units.
Unit case normalizationNormalizes units such as kw to kW.
Strip outer quotesRemoves quotes that wrap the entire cell value.
Global rulesAdds NBSP after initials, abbreviations, and in dates.
Language rulesApplies language-specific spacing rules for EN, FR, DE, ES, NL, and PL.

Output

  • The TXT is tab-separated and ready for InDesign import.
  • The conversion date is added automatically as YY-MM-DD.
  • Line breaks and repeated spaces are cleaned up.
  • Language codes are normalized to short codes where applicable.

XLSX → TXT

Что делает вкладка

Конвертирует XLSX-файлы с переводами в TXT с табуляцией для импорта в InDesign и применяет типографскую очистку при экспорте.

  • Можно загрузить один или несколько XLSX за один запуск.
  • Дата версии добавляется автоматически.
  • Можно добавить суффикс кодировки в имя файла.
  • Все изменения форматирования попадают в лог.

Формат входного файла

  • Строка 1 содержит заголовки или labels.
  • Колонка A содержит коды языков, например en_EN, fr_FR, PL.
  • Остальные колонки содержат тексты, которые станут колонками TXT.
Совет: Добавляйте код проекта в квадратных скобках в имя файла, например Translations [PROJ-001].xlsx. Если кода нет, будет использовано not-set, а в лог попадёт предупреждение.

Как пользоваться

1Загрузите XLSX

Перетащите файлы в upload-зону или нажмите на неё для выбора. Поддерживается несколько файлов.

2Выберите кодировку

Unicode выбран по умолчанию и поддерживает польский и другие не только западноевропейские символы. Mac Roman используйте только для legacy-процессов без центральноевропейских языков.

3Настройте правила

Для обычной работы оставляйте правила включёнными. Отключайте правило только если нужен исходный текст без обработки.

4Сконвертируйте и скачайте

Нажмите Convert. Для каждого файла появится своя ссылка. Скачивание сделано совместимым с Safari.

Результат

  • TXT разделён табуляцией и готов для импорта в InDesign.
  • Дата конвертации добавляется автоматически как YY-MM-DD.
  • Переносы строк и повторные пробелы очищаются.
  • Коды языков нормализуются до короткого вида там, где это применимо.
