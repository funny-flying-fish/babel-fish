XLSX → PPTX

What this tab does

Generates localized PowerPoint files from a marked PPTX and a translated XLSX. It also lets you inspect and tune font-size groups per language before download.

  • Reads language columns from XLSX automatically.
  • Builds a style table from the marked PPTX.
  • Lets you adjust font sizes per language and per style group.
  • Lets you merge several style groups when they should share one size setting.
  • Supports inline markdown for bold and italic inside cells.
  • Can save and load size and style-merge presets as JSON.

Required Files

  • A marked PPTX produced by Prepare PPTX.
  • A translation XLSX with a key column, source column, and language columns such as PL, DE, FR.

How to Use

1Load both files

Drop the marked PPTX into the left upload zone and the translated XLSX into the right upload zone. The style table appears after both files are loaded.

2Review style groups

The table groups similar text styles from the PPTX. Each row has a style number, per-language size fields, visual style information, a selection checkbox, and a usage count.

3Adjust sizes

Edit individual size cells or use the multiplier at the top of a language column to recalculate all sizes for that language.

4Preview examples

Hover style values to preview examples. Click a style value to pin a style card in the right panel; remove it from the panel when you no longer need it.

5Download PPTX

Use the language download buttons at the bottom of the table. The generated file uses your size overrides, merged style groups, and translated text for that language.

Merging Style Groups

Sometimes PowerPoint creates separate style groups that should be treated as one group for translation fitting. You can merge them so they share one reference size.

  • Tick the checkboxes for two or more style rows. A floating toolbar appears next to the first selected style.
  • Click Merge. The first selected style becomes the reference style; all other selected styles are merged into it.
  • Merged rows are highlighted and alias rows show Merged into #.... Alias rows use the reference style's size settings during PPTX generation.
  • To undo a merge, select the merged reference or alias row and click Unmerge.
  • Save a preset if you want to reuse the same merge map and size settings later.

Presets

Save preset downloads a JSON file with current size settings, language multipliers, and style merges. Load preset applies it later to the same or compatible presentation.

Inline Markdown

  • **bold**, *italic*, and ***both*** are converted back to inline PowerPoint formatting.
  • Style table bold/italic acts as the base style; markdown refines specific text segments.
  • Broken markers produce a warning and plain text fallback.

XLSX → PPTX

Что делает вкладка

Собирает локализованные PowerPoint-файлы из размеченного PPTX и XLSX с переводами. Перед скачиванием можно проверить стили и настроить размеры шрифта для каждого языка.

  • Автоматически читает языковые колонки из XLSX.
  • Строит таблицу стилей из размеченного PPTX.
  • Позволяет настраивать размеры по языкам и группам стилей.
  • Позволяет объединять разные группы стилей, если они должны использовать один размер.
  • Поддерживает inline markdown для bold и italic внутри ячеек.
  • Умеет сохранять и загружать presets с размерами и объединениями стилей.

Нужные файлы

  • Размеченный PPTX, полученный через Prepare PPTX.
  • XLSX с переводами: колонка key, исходный язык и языковые колонки вроде PL, DE, FR.

Как пользоваться

1Загрузите оба файла

Размеченный PPTX загрузите слева, XLSX с переводами - справа. Таблица стилей появится после загрузки обоих файлов.

2Проверьте группы стилей

Таблица группирует похожие текстовые стили из PPTX. В строке есть номер стиля, поля размеров по языкам, визуальные параметры, чекбокс выбора и количество использований.

3Настройте размеры

Можно менять отдельные ячейки или использовать multiplier вверху языковой колонки, чтобы пересчитать все размеры для языка.

4Проверяйте примеры

Наведите курсор на значение стиля, чтобы увидеть примеры. Клик по значению закрепляет карточку стиля в правой панели; её можно удалить, когда она больше не нужна.

5Скачайте PPTX

Используйте кнопки языков внизу таблицы. В файл попадут ваши размеры, объединения стилей и переведённый текст выбранного языка.

Объединение групп стилей

Иногда PowerPoint создаёт несколько отдельных групп стилей, хотя для подгонки перевода их удобнее считать одним стилем. Такие группы можно объединить, чтобы они использовали один reference-размер.

  • Отметьте чекбоксами две или больше строк стилей. Рядом с первой выбранной строкой появится плавающая панель.
  • Нажмите Merge. Первый выбранный стиль станет reference-стилем, остальные выбранные стили объединятся с ним.
  • Объединённые строки подсвечиваются, а alias-строки показывают Merged into #.... При генерации PPTX они используют размеры reference-стиля.
  • Чтобы отменить объединение, выберите reference-строку или alias-строку и нажмите Unmerge.
  • Сохраните preset, если хотите потом применить те же размеры и карту объединения стилей.

Presets

Save preset скачивает JSON с текущими размерами, multipliers и объединениями стилей. Load preset применяет его позже к той же или совместимой презентации.

Inline markdown

  • **bold**, *italic* и ***both*** превращаются обратно в inline-форматирование PowerPoint.
  • Bold/italic из таблицы стилей работает как база, markdown уточняет отдельные фрагменты.
  • Сломанные маркеры дают предупреждение и plain text fallback.
