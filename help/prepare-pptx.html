Prepare PPTX

What this tab does

Prepares a PowerPoint file for translation by adding stable translation IDs to text containers and exporting an XLSX template from the same marked file.

  • Creates or repairs names like tr_7f3a91_body in the PowerPoint Selection Pane.
  • Preserves valid existing IDs and repairs duplicates.
  • Exports text by PowerPoint paragraph, not visual line wrap.
  • Table cells get content-hash keys (__h<hash>) so adding rows does not shift other keys.
  • Exports inline bold/italic as markdown markers inside XLSX cells.

How to Use

1Upload the PPTX

Drop the original or already marked presentation into the upload zone.

2(Optional) Upload previous XLSX

Drop your last translation XLSX into the optional zone to migrate custom keys forward. Custom (non-auto) keys are matched by EN text within the same table.

3Set source language

Enter the source language column name, usually EN.

4Run Prepare PPTX

Click Prepare PPTX. The key editor opens; from there you can rename keys, apply bulk operations, and download both the marked PPTX and the XLSX template.

Key editor

  • Keys are grouped by slide and container. Edit any key inline.
  • Apply prefix prepends a string to all keys on the chosen slide (e.g. s5_).
  • Apply basename renames every paragraph in the chosen container to <basename>_1, <basename>_2, ...
  • Reset selected to auto reverts checked rows to their auto-generated key.
  • Prefix and basename accept only A-Z, a-z, 0-9, _ and ..

Output Files

  • *_marked.pptx - the file used later in XLSX ? PPTX.
  • *.xlsx - the translation template (reflects your key edits).
  • *_report.xlsx appears when there are warnings worth reviewing.

You can edit key. Auto keys (tr_..._table__h... or tr_..._body__p...) get regenerated on the next Prepare PPTX; custom names you choose are preserved when you provide the previous XLSX. Do not edit shapeName or slideNumber.

Inline Formatting

  • **bold** for bold.
  • *italic* for italic.
  • ***both*** for bold italic.
  • \* for a literal asterisk.

Run Prepare PPTX again after duplicating slides or making large structural edits. Drop the previous XLSX into the optional zone to keep custom names alive.
