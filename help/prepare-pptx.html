Prepare PPTX

What this tab does

Prepares a PowerPoint file for translation by adding stable translation IDs to text containers and exporting an XLSX template from the same marked file.

  • Creates or repairs names like tr_7f3a91_body in the PowerPoint Selection Pane.
  • Preserves valid existing IDs and repairs duplicates.
  • Exports text by PowerPoint paragraph, not visual line wrap.
  • Exports inline bold/italic as markdown markers inside XLSX cells.

How to Use

1Upload the PPTX

Drop the original or already marked presentation into the upload zone.

2Set source language

Enter the source language column name, usually EN.

3Run Prepare PPTX

Click Prepare PPTX. Download both the marked PPTX and the XLSX template.

Output Files

  • *_marked.pptx - the file used later in XLSX → PPTX.
  • *.xlsx - the translation template.
  • *_report.xlsx appears when there are warnings worth reviewing.

XLSX Format

keyENPLDE
tr_7f3a91_body__p0Original textPolish textGerman text
Do not edit key. It tells the generator where each paragraph belongs.

Inline Formatting

  • **bold** for bold.
  • *italic* for italic.
  • ***both*** for bold italic.
  • \* for a literal asterisk.

Run Prepare PPTX again after duplicating slides or making large structural edits.

Prepare PPTX

Что делает вкладка

Готовит PowerPoint к переводу: добавляет стабильные translation IDs к текстовым контейнерам и выгружает XLSX-шаблон из того же размеченного файла.

  • Создаёт или чинит имена вроде tr_7f3a91_body в Selection Pane.
  • Сохраняет валидные существующие ID и исправляет дубли.
  • Экспортирует текст по абзацам PowerPoint, а не по визуальным переносам.
  • Экспортирует inline bold/italic как markdown-маркеры внутри XLSX.

Как пользоваться

1Загрузите PPTX

Перетащите оригинальную или уже размеченную презентацию в upload-зону.

2Укажите исходный язык

Введите имя колонки исходного языка, обычно EN.

3Запустите Prepare PPTX

Нажмите Prepare PPTX. Скачайте размеченный PPTX и XLSX-шаблон.

Выходные файлы

  • *_marked.pptx - файл, который потом нужен на вкладке XLSX → PPTX.
  • *.xlsx - шаблон перевода.
  • *_report.xlsx появляется, если есть предупреждения для проверки.

Формат XLSX

keyENPLDE
tr_7f3a91_body__p0Original textPolski tekstDeutscher Text
Не меняйте key. По нему генератор понимает, куда вернуть каждый абзац.

Inline-форматирование

  • **bold** для жирного.
  • *italic* для курсива.
  • ***both*** для жирного курсива.
  • \* для звёздочки как символа.

Запускайте Prepare PPTX заново после дублирования слайдов или больших структурных правок.
