Lokalise Export

What this tab does

Synchronizes keys and English source text from an XLSX file with a Lokalise project.

  • Creates keys that are present in XLSX but missing in Lokalise.
  • Updates existing English source text.
  • Optionally deletes keys missing from XLSX.
  • Shows a preview and creates a PDF report after export.

API Token

Create a token at app.lokalise.com/profile/#apitokens, paste it into the API Token field, and click Load Projects.

Security: The token is not saved by Babel Fish.

XLSX Format

Column AColumn B
Key nameEnglish source text
  • Row 1 is treated as a header and skipped.
  • Only key names and English source text are synchronized.
  • Other language translations in Lokalise are not edited.

How to Use

1Load projects

Paste the token, click Load Projects, and choose the target project.

2Upload XLSX

Select the file with key names and English source text.

3Preview and export

Click Preview Diff. If it is correct, click Run Export.

Lokalise Export

Что делает вкладка

Синхронизирует ключи и английский исходный текст из XLSX с проектом Lokalise.

  • Создаёт ключи, которые есть в XLSX, но отсутствуют в Lokalise.
  • Обновляет существующий английский source text.
  • Опционально удаляет ключи, которых нет в XLSX.
  • Показывает preview и создаёт PDF-отчёт после экспорта.

API token

Создайте токен на app.lokalise.com/profile/#apitokens, вставьте его в поле API Token и нажмите Load Projects.

Безопасность: Babel Fish не сохраняет токен.

Формат XLSX

Колонка AКолонка B
Имя ключаАнглийский source text
  • Строка 1 считается заголовком и пропускается.
  • Синхронизируются только имена ключей и английский source text.
  • Переводы на других языках в Lokalise не редактируются.

Как пользоваться

1Загрузите проекты

Вставьте токен, нажмите Load Projects и выберите проект.

2Загрузите XLSX

Выберите файл с ключами и английским исходным текстом.

3Проверьте preview и экспортируйте

Нажмите Preview Diff. Если всё корректно, нажмите Run Export.
