Merge XLSX

What this tab does

Copies translation columns from an old XLSX into a new XLSX when the key and English source text match.

  • Useful after re-running Prepare PPTX for an edited presentation.
  • Preserves the new file's keys and English text.
  • Copies language columns from the old file.
  • Shows changed English rows with a manual Save option.

Required Format

  • Both files must contain key and EN columns.
  • The new XLSX is the base file that keeps its rows.
  • The old XLSX is the source of existing translation columns.
  • Inline markdown markers are ignored when comparing English text.

How to Use

1Load the new XLSX

Drop the newly exported XLSX into the new upload zone.

2Load the old XLSX

Drop the previous translated XLSX into the old upload zone.

3Merge

Click Merge. Download the merged XLSX and review the summary.

Manual Save for Changed EN

Changed English rows appear with Save checkboxes. Tick rows where you trust the old translations, then click Merge again.

Merge XLSX

Что делает вкладка

Копирует колонки с переводами из старого XLSX в новый XLSX, когда совпадают key и английский source text.

  • Полезно после повторного Prepare PPTX для изменённой презентации.
  • Сохраняет ключи и английский текст нового файла.
  • Копирует языковые колонки из старого файла.
  • Показывает строки с изменённым EN и даёт ручную опцию Save.

Требуемый формат

  • В обоих файлах должны быть колонки key и EN.
  • Новый XLSX - базовый файл, его строки сохраняются.
  • Старый XLSX - источник существующих колонок с переводами.
  • Inline markdown-маркеры игнорируются при сравнении английского текста.

Как пользоваться

1Загрузите новый XLSX

Перетащите новый экспортированный XLSX в зону new.

2Загрузите старый XLSX

Перетащите предыдущий переведённый XLSX в зону old.

3Смерджите

Нажмите Merge. Скачайте merged XLSX и проверьте summary.

Ручной Save для изменённого EN

Строки с изменённым английским появляются с чекбоксами Save. Отметьте строки, где старым переводам можно доверять, затем нажмите Merge again.
