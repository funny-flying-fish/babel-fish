Find Difference

What this tab does

Compares two XLSX files by key and English source text, then writes differences into the Utilities log.

  • Finds missing keys and extra keys.
  • Finds keys with changed English text.
  • Reports duplicate keys in either file.
  • Shows a clean no-differences message when files match.

Input Format

  • Both files must be XLSX.
  • Column A is the key name.
  • Column B is English source text.
  • Row 1 is treated as a header and skipped.

How to Use

1Choose File A

Usually this is the older or reference XLSX.

2Choose File B

Usually this is the newer XLSX you want to check.

3Compare

Click Compare. Results appear in the log below the page.

Find Difference

Что делает вкладка

Сравнивает два XLSX по ключу и английскому source text, а затем пишет отличия в Utilities log.

  • Находит отсутствующие и лишние ключи.
  • Находит ключи с изменённым английским текстом.
  • Сообщает о дублях ключей в каждом файле.
  • Показывает понятное сообщение, если отличий нет.

Формат входных файлов

  • Оба файла должны быть XLSX.
  • Колонка A - имя ключа.
  • Колонка B - английский source text.
  • Строка 1 считается заголовком и пропускается.

Как пользоваться

1Выберите File A

Обычно это старый или эталонный XLSX.

2Выберите File B

Обычно это новый XLSX, который нужно проверить.

3Сравните

Нажмите Compare. Результаты появятся в логе под страницей.
